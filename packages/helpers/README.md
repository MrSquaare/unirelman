## About

Provides versioning schemes, prereleases, groups and Git tag names, so plugins behave like the built-in ones.

## Getting started

### Prerequisites

1. Install [Node.js](https://nodejs.org/) 24 or later
2. Set up unirelman: see [Get started](https://mrsquaare.github.io/unirelman/introduction/getting-started/)

### Installation

1. Install the package:

```shell
npm install @unirelman/helpers
```
