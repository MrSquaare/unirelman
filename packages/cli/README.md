## About

Runs the `version` and `publish` pipelines and the plugin commands, and provides `defineConfig` and `defineCommand`.

## Getting started

### Prerequisites

1. Install [Node.js](https://nodejs.org/) 24 or later

### Installation

1. Install the package:

```shell
npm install -D @unirelman/cli
```

## Usage

See the available commands:

```shell
npx unirelman --help
```

See the [documentation](https://mrsquaare.github.io/unirelman/reference/cli/).
