## About

Runs commands, parses JSON and releases resources for the unirelman packages.

## Getting started

### Prerequisites

1. Install [Node.js](https://nodejs.org/) 24 or later

### Installation

1. Install the package:

```shell
npm install @unirelman/utils
```
